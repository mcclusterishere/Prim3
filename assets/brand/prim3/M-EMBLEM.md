# M Emblem (institutional)

## Lockup (owner asset)
- Field: black
- Primary: geometric **white M** (angular, chevron-like negative space in the center)
- Accent: **two red parallelogram bars** (Dual Sight) lower-left of the M, stacked, angled parallel to the M’s left stroke

## Colors
| Element | Hex (approx) |
|---------|----------------|
| Background | `#000000` |
| M | `#FFFFFF` |
| Dual Sight bars | `#E31C23` / strong red |

## Meaning
- **M** = institutional identity (McCluster / Prim3)
- **Dual Sight bars** = split vision / two-state doctrine (not Hitman halo, not Whip wrench-key)

## Usage on gear
| Asset class | Placement |
|-------------|-----------|
| DECK-STD / HARD | Top face corner OR lid corner, ~20–30 mm mark; bars readable |
| DECK-LITE | Face corner, smaller ~15 mm |
| CARRIER-E | Center chest ID panel or upper left chest |
| WRITEBLOCK / IMG-STORE / SEAL | Laser-etched or pad-print small M (optional bars if space) |
| SDR-BRICK | Tiny engraved M on aluminum body |
| Soft goods (IFAK) | Optional subdued grey M; red bars only if high-vis not a liability |
| DENIED profile | M present but **bars muted/grey** or covered |

## Never
- Hitman HM + ammo halo on Prim3 kit
- Whip Equipped wrench-key on Prim3 kit
- Consumer RGB or third-party logos replacing the M
