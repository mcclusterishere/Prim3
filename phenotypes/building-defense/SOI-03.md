# SOI-03 — Technical Facility Security

## Class
**Building Defense**

## Function
Protects high-value technical zones inside McCluster facilities — server rooms, labs, fabrication floors, network cores, and other spaces where physical access equals systems access. This is the cyber-physical specialist of the building guard force.

Closer to the technical world than SOI-01, still clearly a security officer rather than a field FO-T.

## Visual direction
- Authority Black institutional foundation
- Ultra-thin vest + slightly more visible technical interface (cyberdeck prominence)
- Body camera standard
- Sidearm present, still secondary
- Dual Sight / M marks controlled
- May carry limited technical access tools appropriate to facility systems (not full FO-T exploitation kits)
- Cleaner and more “systems” than SOI-01 patrol posture; less pure threshold than SOI-02

## Equipment emphasis
| Item | Role |
|------|------|
| Corporate foundation | Institutional authority |
| Ultra-thin vest | Minimal protection |
| Body camera | Accountability in sensitive zones |
| Enhanced cyberdeck | Facility systems, camera walls, access logs, environmental alarms |
| Limited technical tools | Badge overrides, port control, basic integrity checks — not field exploitation |
| Sidearm | Last resort |
| Comms | Direct to SOI-01 and facility operations |

## Core responsibilities
- Physical security of technical zones (server rooms, labs, cores)
- Monitoring of facility cyber-physical alarms and access anomalies
- Escort and supervision of vendors / technicians inside sensitive spaces
- Immediate response to digital-physical incidents (door forced + network event, etc.)
- Preserving chain of access and evidence inside high-value rooms
- Coordinating with SOI-01 for human threats and with operations for systems events

## Behavioral expectations
- Treats every physical intrusion into a technical zone as a potential data event
- Higher systems literacy than SOI-01 or SOI-02
- Calm, exact, documentation-heavy
- Will refuse entry even to credentialed personnel if procedure is incomplete
- Does not perform field-style exploitation; defends and preserves

## Social signal
“This room is not just a room. Access here is access to the system.”

## Distinction from FO-T
| SOI-03 | FO-T |
|--------|------|
| Defends facility technical zones | Attacks external target systems |
| Preserves and locks down | Extracts and analyzes |
| Stays inside McCluster space | Deploys into uncontrolled environments |
| Security officer identity | Field operator identity |

## Hard exclusions
Full FO-T exploitation stacks, FO-E entry loads, FO-R observation packages, heavy tactical gear, non-McCluster marks.
