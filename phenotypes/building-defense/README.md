# Building Defense Class

**Building Defense** phenotypes protect McCluster facilities, people, data, and continuity of operations **inside and around corporate-controlled space**. They are not field operators, not police, and not military.

They are the institutional immune system of the building.

## Core distinction

| Class | Domain |
|-------|--------|
| **Building Defense** | Inside / around McCluster-controlled facilities |
| **Field Operators (FO-*)** | External, uncontrolled environments |
| **Cohort Operators (CO-*)** | Institutional mission identity (may wear FO kits when deployed) |

## The Building Defense Triad

| ID | Name | Primary Job |
|----|------|-------------|
| **SOI-01** | Security Officer (Standard) | General facility protection, patrol, incident response |
| **SOI-02** | Access Control Officer | Gates, lobbies, identity verification, entry/exit control |
| **SOI-03** | Technical Facility Security | Server rooms, labs, high-value technical zones, cyber-physical defense |

## Shared rules
- Cyber-first mindset relative to conventional security
- Minimal defensive load — professional institutional appearance preserved
- Exact McCluster marks only
- No SWAT, no military special-forces silhouette, no riot cosplay
- Sidearm is last-resort, not primary identity

## Visual hierarchy
SOI-01 remains the baseline Authority Black security skin.  
SOI-02 and SOI-03 inherit the same institutional language with role-specific gear and posture shifts.
