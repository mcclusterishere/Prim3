# Prim3 Field Kits — look / effect / open source

Three field classes only. Each item: **(1) what it looks like**, **(2) in-game / character effect**, **(3) real open-source or open-hardware anchor**.

# Field-T — Technical Operator

**Job:** Collect and seal the take. Window clock owner.

## Kit core

### 1. Field cyberdeck (standard)
| | |
|--|--|
| **Look** | Thick slab laptop-ish deck, ~13–14" class footprint, matte black shell, minimal bezel, external GPIO/USB-C cluster on one short edge, sling points, no glossy consumer logo |
| **Effect** | Enables Survey / Live Pull / Exploit Step. One deck max. LIVE profile baseline. Encumber: Movement 4 |
| **Open source** | Raspberry Pi–class SBC + FOSS stack (Kali/BlackArch toolset as *game software identity*). DIY cyberdeck community form-factor (hinged slab, external ports). Software: Wireshark, Nmap, open imaging clients |

### 2. Lite / rapid deck
| | |
|--|--|
| **Look** | Half-size slate, phone-to-tablet thickness, clipped to plate or thigh, fewer ports |
| **Effect** | RAPID profile: Live Pull cheaper on Window ticks; integrity cap lower unless sealed upgrade |
| **Open source** | Pi Zero / compute-module pocket decks; same FOSS tool identity, reduced modules |

### 3. Hardened / denied deck
| | |
|--|--|
| **Look** | Same slab geometry, Faraday-leaning sleeve aesthetic, muted Dual Sight, no bright LEDs until opened |
| **Effect** | DENIED profile: −Detection on tech actions; Survey still available; emission discipline |
| **Open source** | Same SBC class + RF discipline practices; software-defined “low noise” profile in rules, not a magic box |

### 4. Write-block bridge
| | |
|--|--|
| **Look** | Palm-sized brick inline on SATA/USB path, single status LED (armed / blocked) |
| **Effect** | Required for full-value Forensic Image; without it integrity ceiling drops |
| **Open source** | Software write-blocking workflows (e.g. forensic imaging stacks around **The Sleuth Kit / Autopsy**, Guymager-class tools). Hardware write-blockers are commercial; game item is the *capability* |

### 5. Imaging stack + dual store
| | |
|--|--|
| **Look** | Rugged SSD pair in sled, labeled A/B, short tether to deck |
| **Effect** | FORENSIC profile: high integrity Take packets; bulk can −1 Extract once |
| **Open source** | Disk imaging via open forensic suites (Sleuth Kit ecosystem); hash verification (SHA family) as Seal fantasy |

### 6. Integrity / seal dongle
| | |
|--|--|
| **Look** | Thumb-device, institutional color band, clicks into deck |
| **Effect** | Seal Take action; locks packet so Window=0 still counts sealed data |
| **Open source** | Signing/hash workflow metaphor (GPG-class integrity), not a proprietary DRM toy |

### 7. Sidearm (shared field)
| | |
|--|--|
| **Look** | Compact service pistol, black, no tacticool clutter |
| **Effect** | Dmg 2–3, Close/Mid, 1 AP; last resort — loud Detection |
| **Open source** | **Game stats only.** No build references |
