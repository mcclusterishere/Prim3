# FO-T — Technical Field Operator

## Function
The data, network, and systems specialist on external deployments. This is the operator who touches the target systems — extraction, forensic imaging, live analysis, bypass, and controlled compromise. In a classic field team this is the primary reason the team is there.

## Visual & gear emphasis
- Lighter armor than FO-E to preserve mobility and device access
- Larger or dual cyberdeck / modular compute
- Multiple data interfaces, write-blockers, imaging tools, and offline storage
- Restrained Dual Sight / `//` still present for team ID
- Gloves optimized for fine device work
- Minimal kinetic load (sidearm primary; long gun rare)

## Core responsibilities
- Target system access and exploitation
- Live network and host analysis under time pressure
- Forensic imaging and selective data extraction
- Technical bypass of access controls
- Maintaining operational security of the team’s own digital footprint while inside the target

## Behavioral expectations
- Highest cognitive load on the team during the technical phase
- Speaks in precise, short technical status updates
- Protects the integrity of collected data as a primary mission value
- Will request more time when the alternative is incomplete or contaminated collection
- Remains relatively static once on the target node; relies on FO-E and FO-R for physical security

## Relationship to other field phenotypes
- Protected by FO-E during the technical window
- Informed by FO-R on external threat state
- Often the last to leave the objective

## Narrative utility
This is the phenotype for the “hands on the keyboard in a hostile facility” sequences. It carries the educational payload of real technical work while remaining under lethal pressure.
