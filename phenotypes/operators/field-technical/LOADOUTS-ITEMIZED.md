# Field-T Technical Operator — itemized loadouts

CoD-style specificity. Low asset count. Every slot is a named item.  
Institutional McCluster kit — not generic milsim.

**Role name:** Field-T Technical Operator  
**Job:** Hands on the target systems.

---

## Universal slots (every Field-T loadout)

These never empty.

| Slot | Item | Notes |
|------|------|-------|
| **Base** | MCC Field Base Suit — Charcoal | Matte technical shirt + trousers; institutional cut |
| **Armor** | MCC Soft Plate — Thin Torso | No thick plates; arms free for device work |
| **Sidearm** | MCC Service Pistol — Compact | Always on; low-profile retention holster |
| **Holster** | MCC Retention Holster — Weak-side or dominant | Clean, no drop-leg cosplay |
| **Comms** | MCC Team Radio — Short + Bone/In-ear | Encrypted team net |
| **ID mark** | Dual Sight or red `//` patch set | Readable to team; can be muted on Denied loadout |
| **Gloves** | MCC Tactile Gloves — Device | High feedback; touchscreen / key compatible |
| **Boots** | MCC Field Boot — Quiet Sole | Durable, not entry-heavy |
| **Recorder** | MCC Body Recorder — Chest or deck-link | Mission record always on |

## Create-a-class constraints (game rules)

1. **Sidearm slot locked** — always MCC Service Pistol — Compact.  
2. **One primary compute** — Standard, Hardened, or Lite; not two decks.  
3. **Max 4 tech modules** from the named pool (Rapid max 2–3).  
4. **No Field-E items** (breach, halligan, entry charges).  
5. **No Field-R items** (long glass, overwatch tripod, perimeter sensors as primary).  
6. **No Prime-N1 exclusive** (M-helmet, Mission Core).  
7. Switching loadout mid-mission = module swap at a safe pause only, not full suit change.
