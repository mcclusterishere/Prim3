# Branding rules for modeling AI

## The mark
Every **Prim3 institutional** field asset must include the **M emblem**:
- White geometric **M**
- Two **red** Dual Sight bars lower-left of the M
- On black or dark matte surface

Full lockup rules: `assets/brand/prim3/M-EMBLEM.md`

## Per-asset placement (default)

| asset_id | Where the M goes |
|----------|------------------|
| DECK-STD | Upper face / lid corner, mark height ~25 mm |
| DECK-LITE | Face corner, mark height ~15 mm |
| DECK-HARD | Same as STD but bars **grey or blacked out** (DENIED) |
| WRITEBLOCK | Top face small etched M (~8 mm) |
| IMG-STORE | End cap or top: small M + A/B stencil |
| SEAL-DONGLE | Body print small M |
| SDR-BRICK | Engraved on aluminum side |
| UAV-MICRO | Arm root or body top, small |
| CARRIER-E | Chest ID panel, mark ~40–50 mm |
| IFAK-E | Optional subdued (grey M, no loud red if stealth) |
| BINOC-R | Optional tiny mark on hinge body |
