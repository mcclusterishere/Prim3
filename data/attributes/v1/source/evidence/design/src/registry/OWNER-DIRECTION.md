# PRIM3 current owner direction

Status: CURRENT USER DIRECTION — catalog records do not amend repository canon.

The owner requested a comprehensive attributes matrix for every game object,
person, phenotype, weapon and ammunition type. The current visual direction uses
featureless black mannequins, differentiated by their uniforms, equipment, role
and country badge. The game and its tools must remain usable on a phone.

Nationality and badge identity are presentation fields. This catalog does not
derive combat ability, intelligence or moral character from nationality,
ethnicity or visual appearance. The repository's phenotype term describes a
reusable institutional visual and functional identity package.

Existing source values are preserved. Proposed fields and ammunition definitions
are design work for review, not implemented game rules. Current unit names do not
automatically identify canon people. An approved mapping must be explicit.
