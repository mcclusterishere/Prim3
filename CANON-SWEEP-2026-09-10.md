# PRIM3 Canon Sweep — 2026-09-10

## Purpose

This sweep records the owner-directed gameplay escalation update and the continuity cleanup performed around it.

The governing gameplay idea is now:

```text
ORDINARY PLAY
    = ensemble mission team, no default Jordan

MISSION REACHES CRITICAL
    -> request Jordan Vale / Wildcard if eligible

JORDAN PRESENT + ELIGIBLE HIGH-VALUE MISSION STILL CRITICAL
    -> request PRIM2 / Apex intervention if eligible

OPPOSING BOARD
    -> eligible Royce Incursion can destabilize the mission
```

## Locked Standard scarcity

- Jordan Wildcard: **2 non-scripted authorizations per season**.
- PRIM2 Apex: **3 non-scripted authorizations across the entire seven-season campaign**.
- Royce: **maximum 2 non-scripted incursions per season**, maximum one per mission, two-mission cooldown after a non-scripted incursion.
- Story-scripted deployments do not consume these pools.

Difficulty modes may tune counts while preserving role identity.

## Locked intervention identities

```text
ENSEMBLE -> solves the mission
JORDAN   -> restores optionality / finds another path
PRIM2    -> expands picture and authority
ROYCE    -> violently destabilizes control and tempo
```

Jordan is not a universal specialist and does not auto-complete technical work.
PRIM2 is not a magic reset button or omniscient deity.
Royce is not simply a high-HP reskin of Jordan.

## Anti-frustration law

The intervention system is deliberately a campaign safety valve.

It should reduce cheap campaign-ending frustration and protect attachment to named characters without erasing consequence.

Interventions may save still-living operators, salvage recoverable evidence/objectives, stabilize extraction, or prevent further collapse.

They may not resurrect dead characters, rewind clocks, restore irrecoverably destroyed evidence, erase Heat/Detection, or retroactively authorize completed misconduct.

## PRIM2 oversight distinction

PRIM2 has privileged standing oversight when mission telemetry is available.

This does **not** equal perfect knowledge or automatic control.

Canonical distinction:

```text
PRIM2 OBSERVING
≠
PRIM2 TAKING OVER THE MISSION
```

The executive request remains a meaningful player/character decision even if PRIM2 can already see the crisis developing.

## Local Episode 02–18 status

The episode **order, songs and mission titles remain canon**.

Many local drafts still contain useful technical incidents, human beats, locations and mission concepts, but their old owner/playable-role assertions are not binding until each episode is deliberately migrated through the current template.

That is an **open authoring task, not a canon contradiction**, because the authority stack now explicitly prevents those drafts from outranking the current ensemble/Wildcard rules.

Migration order for each local episode:

```text
choose human owner
 -> define psychology problem
 -> choose base roster without Jordan by default
 -> choose Jordan scripted / wildcard / locked-out state
 -> define CRITICAL / TERMINAL states
 -> define PRIM2 Apex eligibility
 -> define Royce Incursion eligibility
 -> preserve/upgrade technical incident
 -> write WATCH / PLAY consequences
 -> promote after review
```
