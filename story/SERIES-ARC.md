# PRIM3 Series Arc

## Format
- **Episode length:** ~6 minutes
- **Episodes per season:** 3
- **Song rule:** 1 song ≈ 1 episode theme/intro
- **Songs currently in hand:** 16 (see `story/SONG-CATALOG.md`)
- **Season count:** Fit the songs — **not forced to 7**. Working target: **5 seasons (15 eps)** with room to expand if more tracks arrive. RAID + Ghost close the run.

## Episode shape (every episode)
```
0:00–~2:00   OPENING OP
             Early: Prime executes
             Late: Protagonist executes (after agency unlock)
~2:00–5:00   COHORT SUPPORT
             How the machine (Trainee→Lead, Field T/E/R, defense, authority)
             supported that op
5:00–6:00    ADVANCE + STING
             One progression tick + moral/intel knife
```

## Core myth
- Protagonist rises through **all 13 phenotypes** across the run (slow seat/clearance/role-cycle; job label changes rarely).
- Learns Prime appears to be the villain / double-dealing with **Hitman**.
- **Truth:** Prime plays both boards for a longer good; embedded across systems.
- **End:** Protagonist does not kill Prime. Uploads Prime’s consciousness into the system AI. Prime becomes **Ghost in the Wires** — forever mentor. They effectively rule the system together.
- **RAID** = protagonist attacks Prime (last mission structure).
- **Ghost in the Wires** = last myth / close song.
- **Evil Twin** = season-end confession: origin of dual control over Hitman (see `story/missions/EVIL-TWIN.md`).

## Who opens the op
| Phase | Opener |
|-------|--------|
| Early seasons | Prime |
| After agency gate | Protagonist (under Prime) |
| Turn seasons | Protagonist |
| Final | Protagonist vs Prime (RAID) |

## Progression (slow)
Tracks (one tick per episode):
- **Seat** — how close to the brief / board
- **Clearance** — white → grey → black intel
- **Role cycle** — support through T / E / R / Lead shadow while same job label
- **Agency** — support only → run for Prime → run at Prime

Job title changes at **season boundaries** at most — not every episode.

## Hitman
Multinational opposing Prime publicly. Org tree is a **mirror** of Prim3 (`story/HITMAN-ORG.md`). Prime is double agent; alignment was intentional. Protagonist misreads until it is too late for a clean kill.
