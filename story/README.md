## Authority rule

`CANON.md` remains the root continuity authority. Files marked `PROPOSED` add developed character material without silently overriding unresolved root-canon decisions. `CANON-SWEEP-2026-09-10.md` and `MIGRATION-COMPLETE-2026-09-10.md` are historical snapshots. Jordan Vale in those files is the retired working name for McCluster.
