# Character Relationship State

This file defines how PRIM3 should track interpersonal continuity once named cast dossiers are populated.

For every meaningful pair of recurring characters, track:

- trust level,
- professional dependence,
- affection / attraction,
- resentment,
- shared secrets,
- unresolved debt,
- last major conflict,
- last act of loyalty,
- information asymmetry,
- current physical distance,
- current institutional power imbalance.

## Change events

Relationship state changes after:

- a lie is discovered,
- somebody takes blame,
- somebody saves another person,
- somebody follows or rejects an order,
- a promotion changes rank,
- a romantic boundary moves,
- money is borrowed or withheld,
- private information becomes public,
- somebody is injured,
- somebody dies,
- a mission exposes cowardice or courage,
- one character learns they were being evaluated through another.

## Writing consequence

Writers and AI collaborators should consult the latest relationship state before generating a scene. Characters cannot return to a neutral default merely because a new episode begins.
