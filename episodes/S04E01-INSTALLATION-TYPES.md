# Human problem

A remote/aging site must be migrated under time pressure. Some components can be safely upgraded in place; others must be rebuilt from trusted baseline; one attractive shortcut would make Valeria look brilliant now and create hidden fragility later.

Valeria has spent years wanting to be seen as ready.
This episode asks whether she can choose the option that looks less impressive because it is more responsible.

---

# Technical thesis

Teach:
- clean installation;
- in-place upgrade;
- migration/compatibility;
- backup and rollback;
- trusted baselines;
- dependency inventory;
- validation after change;
- retirement of untrustworthy components.

Core line:

> **Not everything worth preserving should be carried forward.**
